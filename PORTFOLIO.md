# Portfolio case study / 求职作品说明

## English résumé entry

**Travel Guide — Chinese–Thai Tourism Reader | Personal Project**

- Consolidated 351 guide-content entries across four collections into a deployed Chinese–Thai reader, covering airport transfers, Shanghai itineraries, attraction explanations and Jiangnan culture.
- Used AI-assisted development to implement search, language switching, bookmarks, collapsible navigation, adjustable typography, themes and keyboard controls.
- Integrated prerecorded Thai male narration for 11 Jiaxing–Puyuan chapters, with paragraph playback, adjustable speed and timestamp-based seeking/replay.
- Defined and tested a paragraph-to-Chrome-side-panel translation workflow that preserves source content while supporting word-by-word language study.

Live demo: https://jiaxing-puyuan-thai-guide.pages.dev/

## 中文简历项目经历

**行旅 · 中泰导游书｜个人作品**

将四个分类、351 节导游内容整合成可在线体验的中泰双语阅读产品，覆盖接送机、上海三天路线、景点讲解与江南文化。负责需求定义、内容组织、界面体验和结果验证，使用 AI 辅助实现搜索、语言切换、备讲收藏、目录收放、字号与主题设置。接入嘉兴、濮院 11 节泰语男声录音，支持逐段播放、调速、快退和重读；设计正文到 Chrome 插件侧栏的逐字翻译流程，保持原文不受影响。

## A short interview introduction

I speak Chinese, Thai, Japanese and English. This project shows how I use language skills in a specific industry context rather than treating them only as résumé keywords. I brought my tourism material into a working Chinese–Thai reader and used AI to help implement it. I defined the workflow, checked the result and kept improving the reading and rehearsal experience. For example, Chinese mode still needs Thai playback, and a translation tool should not overwrite the original passage. The project is live, so I can demonstrate those choices directly.

Language proficiency here is self-reported; the project demonstrates Chinese–Thai material and does not independently verify Japanese or English proficiency.

## 面试时可以演示的 60 秒流程

1. 打开上海口播，定位接机或景点的一段中泰内容。
2. 切换嘉兴、濮院，播放对应泰语录音并调整语速。
3. 使用分隔线、字号和目录收放展示阅读体验。
4. 在装有兼容扩展的 Chrome 中点击“译”，展示侧栏逐字翻译和保持完整的原文。

## 作品边界

条目总数包含重叠主题。泰语音频目前只覆盖嘉兴、濮院。语音由第三方工具生成，代码由 AI 辅助实现。项目尚无可核实的付费用户、商业收入或使用量数据。
