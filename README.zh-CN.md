# 行旅 · 中泰导游书

## 从实际需要出发

导游准备讲解时，需要快速找到一段内容、理解它的中文含义、练习泰语表达，还需要在现场按路线切换。这些步骤如果分散在不同文档与音频里，使用起来很不方便。

我把自己的导游材料整理成中泰对照阅读产品，并借助 AI 完成开发和迭代，让语言能力、旅游行业内容积累和产品制作能力落在一个可体验的作品上。

支持中泰、中文、泰语三种阅读方式，搜索、收藏备讲、全文与简讲、可收放目录、字号调整和昼夜模式。嘉兴、濮院的 11 节已接入泰语男声录音，共 13 个音频文件；上海和另外两个分类目前只有文字。

每段可点击“译”，送至另行安装的 GPT 随页助手 Chrome 扩展进行逐字翻译。结果只在插件侧栏显示，不改动正文。本仓库不包含该扩展，普通阅读与已有音频播放不依赖它。

## 我的工作

我负责提出和判断使用需求，整理多语言行业内容，确定阅读及朗读体验，并在反复试用后推进修改。代码由 AI 辅助实现，我承担产品方向、结果检查与功能迭代。

具体改进包括：中文阅读时仍保留泰语播放按钮；翻译与正文分离；调整阅读宽度、字体和分隔线；让侧边栏收放；用快捷键调整字号、语速、进度和主题；减少不必要的界面备注。

这是个人作品和工作工具，目前没有宣称付费客户、商业收入或大规模用户。也没有宣称自行训练语音模型、独立完成全部代码，或翻译已经获得专业认证。

## 本地运行

安装 Python 3 后，在仓库目录执行：

```sh
python3 -m http.server 8000
```

浏览器打开 <http://localhost:8000>。不要直接双击 HTML 文件，页面需要通过 HTTP 加载 JSON 内容。

技术为 HTML、CSS、原生 JavaScript、JSON、浏览器 Audio 和 localStorage。线上版本部署于 Cloudflare Pages。录音使用 ElevenLabs 生成，GitHub 版本从线上站点加载音频，不包含 MP3 文件，朗读需要联网。播放与调速不消耗新的语音生成额度。

## 快捷键

- `＋／－`：调整字号。
- `↑／↓`：调整朗读速度（0.5×–2×）。
- 连续两次空格：切换昼夜模式。
- `←／→`：前后调整 3 秒；`R`：重读当前朗读句。

输入框里打字不会触发这些快捷键。句子时间边界基于音频对齐，可能存在误差。收藏和设置保存在当前浏览器。

## 适合作为什么求职证明

这个作品能具体展示中泰内容组织、旅游场景理解、AI 辅助产品开发和持续迭代的能力。面试时可以直接展示一个真实流程：找到导游段落、切换语言、播放泰语、调整语速，再送入侧栏逐字翻译。

它对多语言内容、旅游产品、内容运营及 AI 工具应用方向更有针对性；作为软件工程岗位证明，还需结合代码理解、测试和独立解决问题的过程。

当前不授予开源使用许可。代码、导游文字和音频公开用于作品展示；第三方工具的权利及条款仍归相应提供方。专业带团前应核实旅游事实与翻译。
